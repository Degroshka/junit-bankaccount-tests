# Тест-кейсы: unit-тесты на JUnit 5

Тест-кейсы для классов `BankAccount`, `StringUtils`, `ShoppingCart` и `Product`. Каждый кейс реализуется одним автотестом на JUnit 5 (паттерн Arrange-Act-Assert).

**Приоритет:** H — критичный сценарий, M — важный, L — второстепенный.  
**Статус:** ✅ автотест написан и проходит, ❌ тест нашёл дефект, ⬜ не реализован.
