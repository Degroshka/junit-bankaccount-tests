## BUG-4: `ShoppingCart.clear` скидка сохраняется после очистки корзины
| Поле        | Значение                                            |
|-------------|-----------------------------------------------------|
| Тест-кейс   | TC-3.3.7                                            |
| Компонент   | `ShoppingCart.clear`                                |
| Окружение   | Java 21.0.2, JUnit 5.10.1, Maven, коммит `786bf801` |
| Серьёзность | Minor                                               |
| Приоритет   | Low                                                 |
| Статус      | Open, требуется уточнение требования                |

**Предусловия:**
1. Создать корзину: `cart = new ShoppingCart()`

**Шаги воспроизведения:**
1. Создать продукт: `Product milk = new Product("milk", 100)`.
2. Добавить продукт в корзину: `cart.addItem(milk)`.
3. Установить скидку: `cart.setDiscount(10)`
4. Очистить корзину: `cart.clear()`.
5. Добавить продукт в корзину: `cart.addItem(milk)`.
6. Вызвать: `cart.getTotalPrice()`.

**Фактический результат:** продукты сбрасываются, но скидка остаётся, `cart.getTotalPrice()` возвращает `90`, а должно `100` (Скидка к новой корзине не применялась).

**Ожидаемый результат:** вероятно, скидка должна сбрасываться вместе с продуктами.

**Причина:** `clear` не вызывает сброс скидки.

**Последствия:** сохранение скидки для продукции, не предназначенной для скидок.

**Автотест:** TC-3.3.7 помечен `@Disabled("BUG-4")` до уточнения.
